# External Gazebo models

These model directories are the final 26-object world's dependencies copied from the local Gazebo model database. Their source is the [OSRF Gazebo model database](https://github.com/osrf/gazebo_models). The upstream repository states the Creative Commons Attribution 3.0 Unported license; see [LICENSE](LICENSE). Each `model.config` retains the original model author's name when supplied. The `arm_part` model is a nested dependency of `gear_part`. The project-specific `pcd_bottle` and `pcd_doll` models are under `src/robot_tasks/models/`.
